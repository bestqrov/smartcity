# خارطة الطريق: Smart School / ArwaEduc

> آخر تحديث: 2026-09-20. كتلخص كل ما اتفقنا عليه وما بقى نبنيوه، **بالترتيب المقترح**.
> المنتج: منصة SaaS كتباع للمدارس بـ 3 packs (250 / 400 / 800 درهم شهريًا). الكود: `apps/education-apps` (backend Express + Prisma + MongoDB، وfrontend Next.js).

## 1. ما تبنى وتدمج (خدام)

| الميزة | الحالة | ملاحظات |
|---|---|---|
| **النقل المدرسي** | مدمج ومدفوع لـ GitHub (`main`) | حافلات، سائقون، خطوط، محطات، اشتراكات، دفع شهري + `Transaction` INCOME، بطاقة فـ صفحة التلميذ وفـ بوابة الأولياء. مختبر بـ 198 اختبار وQA حي. Spec: `docs/superpowers/specs/2026-09-19-education-transport-design.md` |
| تعدد المؤسسات (School → Branch) | خدام | `OWNER`، عزل البيانات بـ `branchId`، signup ذاتي للمدارس |

| بوابة الأولياء وبوابة التلميذ، الحضور QR، إشعار الغياب | خدامين | الإشعارات فـ `modules/notifications` وjob الغياب (خاص التحقق من قناة WhatsApp الحقيقية) |

## 2. القرارات المتخذة

- **الـ packs (مستقلة لكل نوع، بأثمنة مختلفة):** مدرسة خاصة 250 / 400 / 800 (100 / 300 / بلا حد، والنقل فـ Premium فقط)، مركز دعم 200 / 350 / 600 (150 / 400 / بلا حد)، تكوين مهني 300 / 500 / 900 (80 / 250 / بلا حد)، معهد لغات 200 / 350 / 650 (120 / 350 / بلا حد)، حضانة 200 (40 طفل). سنوي = 10 أشهر. الفروع: 1 / 2 / بلا حد. **لكل نوع pack افتراضي** (Pro، والحضانة pack الحضانة).
- **نوع المؤسسة أولا:** المدرسة كتختار نوعها (مدرسة خاصة، مركز دعم، تكوين مهني، معهد لغات، **حضانة**) قبل الـ pack. الـ packs كتتفلتر حسب النوع، والقوائم والمصطلحات فـ التطبيق كتتكيف (الحضانة كتشوف "الأطفال"). "الشبكات" ماشي نوعا: كتختار نوعها الأساسي وتعدد الفروع كيتحكم فيه الـ pack.
- **pack الحضانة (Crèche):** 200 درهم شهريا / 2000 سنويا، حتى 40 طفل، فرع واحد، ميزاته `PARENT_PORTAL` و`DAILY_LOG`. الـ packs الأخرى كل نوع عندو ديالو.
- **الميزات المفتاحية:** `PARENT_PORTAL`, `STUDENT_PORTAL`, `QR_ATTENDANCE`, `ANNOUNCEMENTS`, `FINANCE_ANALYTICS`, `TRANSPORT`, `DAILY_LOG`. الفروع كيتحكم فيها `maxBranches`.
- **النقل + Pro:** ما كاين add-on. الـ Super Admin كيكري pack مثل "Pro + Transport" بـ 500 درهم.
- **الـ Super Admin** كيتحكم فـ الـ packs (إضافة/تعديل/إيقاف/افتراضي) وكيربط كل مدرسة بـ pack.
- **الـ landing:** داخل frontend الـ ArwaEduc فـ `/`، بالنمط الغامق (B)، اسم **Smart School**، عربية فصحى وفرنسية مع RTL، و15 يوم تجربة. الـ packs كتتجاب من الـ API.
- **الاسم "Smart School":** كيظهر غير فـ الـ landing وصفحة signup. باقي التطبيق ما تبدلش.
- **WhatsApp:** الزر العائم كيوجه لـ `wa.me/212608183886` (رقم مؤقت، كيتبدل بـ `NEXT_PUBLIC_WHATSAPP_NUMBER`).
- **الأسعار:** ماشي مطبقة كحدود فعلية دابا (تخزين وعرض فقط).

## 3. الترتيب المقترح للبناء

### المرحلة 1: الكتالوج والـ landing (spec وخطتان تقنيتان مكتوبين، باقي التنفيذ)
- الخطط: `docs/superpowers/plans/2026-09-20-education-packs-backend.md` (8 tasks) و`docs/superpowers/plans/2026-09-20-education-packs-frontend.md` (8 tasks). الـ backend أولا.
- **1.1 كتالوج الـ packs + ربط المدارس:** جدول `Pack`، `packId` فـ `School` (كيعوض `packTier`)، API للـ Super Admin، صفحة `/admin/packs`، عمود Pack فـ `/admin/schools`، seed للـ 3 packs. *أساس لكل ما بعده.*
- **1.2 الـ endpoint العمومي `GET /api/packs/public?type=`** و`institutionType` + `packCode` فـ الـ signup (النوع إجباري).
- **1.3 الـ landing `/`:** hero + رسم dashboard، 10 بطاقات مميزات (بوابة الأولياء، بوابة التلميذ، QR، النقل، المدفوعات، التكوينات، الموظفين، الفروع، الإعلانات، المطعم "قريبًا") + بطاقة SmartCities، قسم "لكل أنواع المؤسسات"، الأسعار (شهري/سنوي)، 3 خطوات، وزر WhatsApp.
- **1.4 صفحة signup:** كتقرا `?type=` و`?pack=`، كتطلب النوع إلا ما تحدد، وكتعرض الـ pack المناسب مع إمكانية التبديل.
- **1.5 التكيف حسب النوع:** ملف config واحد كيحدد قوائم الـ sidebar والمصطلحات لكل نوع (الحضانة: "الأطفال" وبلا الدعم والتكوينات، مع مدخل "السجل اليومي — قريبًا").
- Spec: `docs/superpowers/specs/2026-09-20-education-packs-landing-design.md`، والنموذج: `docs/superpowers/specs/assets/2026-09-20-smart-school-landing-mockup.html`.

### المرحلة 1ب: السجل اليومي للحضانة (مشروع مستقل، spec وخطة خاصين به)
- لكل طفل فـ كل يوم: الوجبات، القيلولة، المزاج، تغيير الحفاض، وملاحظات للولي. المربية كتسجل، والولي كيشوف اليوم فـ البوابة (قراءة فقط).
- كيتفعل غير للحضانات (pack عندو `DAILY_LOG`). الـ pack Crèche كيتباع من اليوم الأول والسجل اليومي معلن "قريبًا" حتى يتبنى.
- الميزات الأخرى (التسليم الآمن، الملف الصحي، الصور) اتفقنا ما نبنيوهاش دابا، ونرجعو ليها بعد ما نجربو السجل اليومي مع حضانات حقيقية.

### المرحلة 2: تطبيق الـ packs (spec جديد لازم)
- منع تجاوز `maxStudents` و`maxBranches` (رسالة واضحة + اقتراح ترقية).
- إخفاء/منع الميزات حسب الـ pack (النقل، البوابات، QR، التحليلات، الإعلانات).
- عرض الـ pack والحدود الحالية فـ إعدادات المدرسة.
- *بدون هاد المرحلة الأثمنة كتبقى نظرية.*

### المرحلة 3: فوترة المدارس (spec جديد لازم)
- تسجيل أداء اشتراك المدرسة (فـ البداية يدوي من الـ Super Admin: تحويل بنكي/نقدا)، تواريخ التجديد، الفواتير.
- تحويل التجربة لاشتراك مدفوع وما يترتب عليه (تفعيل/إيقاف تلقائي حسب انتهاء الاشتراك).
- لاحقًا: الدفع الإلكتروني (CMI) إلا كان مطلوبًا.

### المرحلة 4: ميزات جديدة معلنة فـ الـ landing
| الميزة | الوضع | قبل البناء |
|---|---|---|
| **المطعم المدرسي (Cantine)** | بطاقة "قريبًا" | نحددو: قوائم الوجبات، تسجيل التلاميذ، الأداءات، الحساسية الغذائية؟ |
| **دليل SmartCities المغرب** | بطاقة تسويقية بلا وظيفة | نحددو معناه: صفحة عامة للمدرسة، أو رابط للموقع الرئيسي، أو شي حاجة أخرى |

### المرحلة 5: تحسينات النقل (صغيرة)
- **واجهة السكرتيرة** للنقل (دابا admin/owner فقط).
- قرار واضح لـ **الاشتراك الموقوف (PAUSED)**: واش يقبل الدفع ويحرر المقعد (دابا كيدير هاكا).
- **ObjectId غالط فـ الـ URL** كيعطي 500 عام؛ الأحسن 400/404.
- شيل `portalTokenHash` من رد بروفايل الوالدين (مشكل قديم قبل النقل).
- سباقات (race) الدفع المزدوج والاشتراك المزدوج: مخفف بتعطيل الزر، وحل حقيقي يحتاج قفل أو index جزئي.

## 4. أسئلة مفتوحة (خاصنا نجاوبو عليها)

1. **معنى "التسجيل فـ SmartCities المغرب"** (دليل عام؟ رابط؟) قبل ما نبنيو أي حاجة.
2. **ميزات الحضانات بعد السجل اليومي:** التسليم الآمن (أشخاص مرخص لهم + QR)، الملف الصحي، الصور والأنشطة. نقرروها بعد تجربة السجل اليومي مع حضانات حقيقية.
3. **رقم WhatsApp النهائي** (دابا 0608183886 مؤقتا).
4. **الأسعار والحدود:** تحقق مع 5 – 10 مدارس حقيقية قبل الإطلاق (100 / 300 تلميذ، 250 / 400 / 800 درهم).
5. **الاسم:** واش "Smart School" غادي يعم التطبيق كامل (login، sidebar…) ولا يبقى غير فـ الـ landing؟
6. **نهاية التجربة:** واش المدرسة تبقى تشوف بياناتها فـ وضع قراءة فقط بعد 15 يوم؟ (دابا الـ middleware كيمنعها كليا).

## 5. اقتراحات ماشي قرارات (للتفكير فقط)

- تقارير المدير (نسب الحضور، المداخيل، أكثر المتأخرين فـ الأداء) كـ ميزة `FINANCE_ANALYTICS`.
- تطبيق موبايل/PWA لبوابة الأولياء.
- تصدير Excel/PDF للوائح والوصولات.
- ربط الإشعارات بـ WhatsApp Business API رسميًا (إن لم تكن الحالية كافية).
- نسخ احتياطي واستيراد التلاميذ من Excel لتسهيل انتقال المدارس الجديدة.
